# Documentação da API com Swagger

> *Episódio: o cardápio vivo da API em `/api`.*

## Objetivo deste material

Ao terminar, você deve conseguir:

1. Subir a UI Swagger em **`http://localhost:3000/api`**.
2. Documentar as rotas **P** (produtos, pedidos, auth) com tags, summary e respostas.
3. Configurar **Bearer JWT** no Swagger (`Authorize`) e testar rotas protegidas pela UI.
4. Anotar DTOs com `@ApiProperty` para o schema aparecer no “Try it out”.

## 1. Por que documentar?

A `loja-api` já tem muitas rotas. Sem documentação viva, Ana e o front dependem de curls espalhados.

> **Conceito: OpenAPI / Swagger**  
> Contrato legível da API (paths, bodies, auth). No Nest, `@nestjs/swagger` **gera** o documento a partir de decorators + tipos.

```mermaid
flowchart LR
    Codigo[Controllers + DTOs] --> NestSwagger[@nestjs/swagger]
    NestSwagger --> Spec[OpenAPI JSON]
    Spec --> UI[Swagger UI /api]
```

## 2. Instalar e ligar no `main.ts`

```bash
npm install @nestjs/swagger
```

```typescript
import { NestFactory } from '@nestjs/core';
import { DocumentBuilder, SwaggerModule } from '@nestjs/swagger';
import { AppModule } from './app.module';
import { ValidationPipe } from '@nestjs/common';

async function bootstrap() {
  const app = await NestFactory.create(AppModule);

  app.useGlobalPipes(
    new ValidationPipe({
      whitelist: true,
      forbidNonWhitelisted: true,
      transform: true,
      transformOptions: {
        enableImplicitConversion: true, // igual ao cap. 2.1 — não remova ao adicionar Swagger
      },
    }),
  );

  const config = new DocumentBuilder()
    .setTitle('loja-api')
    .setDescription('API da trilha NestJS — linha P')
    .setVersion('1.0')
    .addBearerAuth()
    .build();

  const document = SwaggerModule.createDocument(app, config);
  SwaggerModule.setup('api', app, document);

  await app.listen(3000);
}
bootstrap();
```

Abra: `http://localhost:3000/api`.

> **Conceito: `addBearerAuth()`**  
> Habilita o botão **Authorize** na UI. O valor é o JWT **sem** a palavra `Bearer` (a UI prefixa).

## 3. Tags e operações no controller

```typescript
import { ApiBearerAuth, ApiOperation, ApiResponse, ApiTags } from '@nestjs/swagger';

@ApiTags('products')
@Controller('products')
export class ProductsController {
  @Get()
  @ApiOperation({ summary: 'Listar produtos' })
  @ApiResponse({ status: 200, description: 'Lista de produtos' })
  findAll() {
    return this.productsService.findAll();
  }

  @Post()
  @ApiBearerAuth()
  @ApiOperation({ summary: 'Criar produto (ADMIN)' })
  @ApiResponse({ status: 201, description: 'Criado' })
  @ApiResponse({ status: 401, description: 'Sem token' })
  @ApiResponse({ status: 403, description: 'Papel insuficiente' })
  create(@Body() dto: CreateProductDto) {
    return this.productsService.create(dto);
  }
}
```

Faça o análogo em `orders` e `auth` (`@ApiTags('orders')`, `@ApiTags('auth')`).

## 4. DTOs visíveis no schema

```typescript
import { ApiProperty } from '@nestjs/swagger';
import { IsInt, IsNumber, IsString, Min, MinLength } from 'class-validator';

export class CreateProductDto {
  @ApiProperty({ example: 'Caneca Nest', minLength: 2 })
  @IsString()
  @MinLength(2)
  name: string;

  @ApiProperty({ example: 39.9, minimum: 0.01 })
  @IsNumber({ maxDecimalPlaces: 2 })
  @Min(0.01)
  price: number;

  @ApiProperty({ example: 10, minimum: 0 })
  @IsInt()
  @Min(0)
  stock: number;
}
```

Sem `@ApiProperty`, o Swagger muitas vezes mostra body vazio ou genérico demais.

## 5. Linha P — roteiro na UI

Documente **só** o que já existe (produtos, pedidos, auth/roles). Rotas de imagem ficam para o cap. 9.

1. Abra `/api`.  
2. `POST /auth/register` e `POST /auth/login` (Try it out).  
3. Copie o `access_token` → **Authorize**.  
4. `POST /products` com body válido (usuário ADMIN).  
5. `GET /products` sem auth.  
6. Confira respostas 401/403 documentadas batendo com o comportamento real.
